# Sample PDFs Directory

This directory contains sample PDF files used for testing and development.

## File Categories

### Template PDFs
Original blank PDF forms used as templates:
- `1099-DIV.pdf` - Original 1099-DIV form template

### Generated PDFs
PDFs generated by the tax document generation system:
- `test-output-1099-DIV.pdf` - Test output from document generation
- `test-output-multi-copy-1099-DIV.pdf` - Multi-copy test output
- `downloaded-1099-DIV.pdf` - Downloaded test output
- `pymupdf-generated-1099-DIV.pdf` - PyMuPDF migration test output
- `pymupdf-v2-1099-DIV.pdf` - PyMuPDF v2 test output
- `fresh-generated-1099-DIV.pdf` - Fresh generation test
- `final-fix-1099-DIV.pdf` - Final fix verification

### Test PDFs
PDFs used for specific testing scenarios:
- `SAMPLE-1099-DIV-MULTI-COPY.pdf` - Multi-copy sample form
- `test-comprehensive-field-mapping-1099-DIV.pdf` - Comprehensive field mapping test
- `with-need-appearances-1099-DIV.pdf` - NeedAppearances flag test

### Downloaded PDFs
PDFs downloaded during testing:
- `downloaded-1099-DI1V.pdf` - Downloaded test (note typo in filename)

## Usage

These PDFs are used by:
- Integration tests in `tax_document_generation/tests/`
- Manual testing scripts in `scripts/`
- Field mapping validation
- Visual verification of generated documents

## Viewing PDFs

To view these PDFs:

```bash
# macOS
open samples/1099-DIV.pdf

# Linux
xdg-open samples/1099-DIV.pdf

# Windows
start samples/1099-DIV.pdf
```
